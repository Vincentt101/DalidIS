# Typing Master

A typing game that installs on iPhone/iPad like a normal app (it's a web app, so no App Store needed).

**Modes**
- **Word Rain** – words fall from the sky; type them before they land. 3 lives, levels speed up, combos multiply your score, gold words are worth 3x and give back a heart. Easy / Normal / Hard.
- **Speed Test** – 15, 30 or 60 seconds. Shows words per minute (WPM) and accuracy.

Best scores are saved on the device. Works offline after the first visit.

## Install on iPhone
1. Host the repo on GitHub Pages (repo **Settings → Pages → Deploy from a branch → `main` / root**).
2. On the iPhone, open **Safari** and go to `https://vincentt101.github.io/DalidIS/typing/`
3. Tap **Share** (square with arrow) → **Add to Home Screen** → **Add**.
4. Open "Typing Master" from the home screen. It runs full screen like any app.
